Per verificare il tuo sito su Google Search Console, segui uno di questi metodi:

Metodo 1: Meta Tag (raccomandato)

Il meta tag è già presente nel file src/app/layout.tsx alla riga 40-42:

  verification: {
    google: "google-site-verification-code",
  },

Sostituisci google-site-verification-code con il codice di verifica fornito da Google Search Console.

Metodo 2: File HTML

Carica il file fornito da Google nella directory public/ del progetto. Il file sarà accessibile all'indirizzo:

https://maxthenics.com/NOME_FILE.html

Nota: Questo file è solo un placeholder. Usa il file effettivo scaricato da Google Search Console.
